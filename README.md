# GuardianMine — AI-Powered Miner Safety Monitoring System (Hackathon Prototype)

A real-time command center dashboard monitoring environmental hazards (Methane, CO) and biological vitals (Heart Rate, Body Temp) for underground personnel. Calculates a dynamic Machine Learning Risk Score (0-100%) and delivers actionable emergency dispatch instructions.

---

## Quick Setup & Execution Guide

### 1. Prerequisites
Ensure you have **Python 3.9+** installed on your platform.

### 2. Environment Setup & Dependencies
```bash
# Clone or navigate into project directory
cd miner-safety-system

# Create virtual environment (Optional but Recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install required dependencies
